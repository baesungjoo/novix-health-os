# NOVIX Health OS v2 — 3H 영도센터

## 가장 쉬운 실행 방법

### 처음 한 번
1. 압축을 풉니다.
2. 폴더 안의 `처음설치하고실행.bat`를 더블클릭합니다.
3. 설치가 끝나면 브라우저가 자동으로 열립니다.

### 다음부터
- `다음부터실행.bat`를 더블클릭합니다.

## 직접 실행하는 방법

VS Code 터미널에서 아래를 차례로 입력합니다.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저 주소: `http://localhost:3000`

## 체험 로그인

- 이메일: `admin@3h.co.kr`
- 비밀번호: `1234`

## 포함 기능

- 관리자 로그인
- 대시보드
- 회원 관리
- 예약 관리
- 공지사항
- 갤러리
- AI 문구 작성 데모
- 센터 설정

## 참고

현재 버전은 로컬 데모용 MVP입니다. 입력한 데이터는 새로고침하면 초기화될 수 있습니다. 실제 운영용 영구 저장은 Supabase 연동 단계에서 추가합니다.
